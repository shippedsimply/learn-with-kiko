# Learn with Kiko

A friendly learning app for children: reading (letter sounds, blending, word families, sentences, stories), writing,
maths, thinking, the world around us, feelings and everyday life skills. Kiko the parrot talks the child through
everything in a warm, natural voice, so it works for children who can't read yet.

**Kiko by Lathan**, made with love for learning.

## Open it

- **iPad / iPhone / Android / any computer:** open **https://shippedsimply.github.io/learn-with-kiko/**
  - On an iPad or iPhone, tap **Share → Add to Home Screen**. Kiko then opens like an app and works without internet.
- **Windows laptop:** download the Kiko program from the [Releases page](https://github.com/shippedsimply/learn-with-kiko/releases/latest)
  (`Learn-with-Kiko-Setup-….exe`). It works fully offline.

Progress is saved on the device. Grown-ups can make a backup (Grown-ups → 💾 Backup) and load it on another device.

## Feedback

Tap **♥ Kiko by Lathan** at the bottom of any screen → **💬 Send feedback**, or open an
[issue](https://github.com/shippedsimply/learn-with-kiko/issues/new?title=%5BFeedback%5D%20). Notes titled
`[Feedback]` are also saved in the [`feedback/`](feedback/) folder. Issues on GitHub can be read by anyone.
