# Feedback

Notes from the app's **💬 Send feedback** button that were sent as GitHub issues (titled `[Feedback] …`).
`issues.jsonl` gets one JSON line per issue (`num`, `title`, `body`, `at`, `url`, `by`), added automatically by
`.github/workflows/feedback.yml`. Notes saved in the app itself can be downloaded from Grown-ups → 💬 Feedback and
dropped in this folder too.
